Fonts bundled with the app so the band name looks the same on every computer. All are from
Google Fonts (https://github.com/google/fonts) and released under the SIL Open Font License 1.1
(see OFL.txt): Anton, Bebas Neue, Major Mono Display, Monoton, Montserrat, Pacifico,
Playfair Display, Righteous. Any font installed on the system can be used as well.
