How it works

In the app

  1. In Elements, click Add and pick a shape: a sunset sun, a horizontal beam, a hexagon, a ring, vertical blocks, light shafts or horizon lights.
  2. Change its size, position and look with the sliders. Each shape shows only the settings it needs, like the number of bars or a beam's segments.
  3. Drag it around in the preview and use the mouse wheel to resize it.
  4. Tick it in the list for each pattern that should use it. The ticks follow the pattern picked at the top.
  5. The preview pulses only the shape you're editing, so you see exactly what it does.
