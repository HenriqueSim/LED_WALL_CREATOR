How it works

In the app

  1. File → New Project asks for a name and where to keep it (Documents/LED Wall Creator by default).
  2. Leave Create a folder for the project on: you get the project file plus Media and Backups folders.
  3. Loaded audio is copied into Media, and stored relative to the project so the folder can move.
  4. Every save keeps the previous version in Backups (the newest 20).
  5. Double-click a .ledwall file to open it. File → Open Recent has your last projects.
