Always the latest, in one click.

When a new version comes out, the app tells you when it starts. One click downloads it, installs it next to the current one and restarts. Your projects are never touched.

How it works

In the app

  1. When the app starts it checks quietly for a new version (it stays silent when you're offline).
  2. If there is one, you see what's new and choose Install update, Later or Skip this version.
  3. It downloads, installs, restarts into the new version and removes the old one.
  4. Anything you kept inside the app's folder is moved to the new version first. If a file can't be moved, the old version is kept.
  5. Help → Check for Updates checks by hand, and the automatic check can be turned off.
